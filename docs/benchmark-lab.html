Measurement boundary: `llama-bench` measures prompt processing and token-generation throughput under synthetic workloads. It does not measure first-token latency, maximum resident RAM, maximum GPU VRAM, model quality, or cold-start disk I/O. Those remain null in the candidate file. A 16 GiB test system is not proof a model's minimum RAM is 16 GiB.

After running

Read the candidate JSON locally and double-check source URL, build SHA, model quantization and physical hardware. For a more complete report, independently collect peak RSS/VRAM, cold-start timing and disk I/O. Include the sampling method and logs.
