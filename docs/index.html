Evidence, not hype

Understand what these projects really measure.

01 · Total RAM ≠ peak memory

A 16 GB test machine is not a 16 GB minimum requirement. We label measured RSS, VRAM, and unified-memory metrics separately.

02 · SSD capacity matters

An 8 GB model runtime can still demand terabytes of stored weights. Check full checkpoint, converted files, and cache sizes.

03 · Source-reported ≠ reproduced

The numbers shown here come from upstream project reports. We never imply independent verification or cross-model performance rankings.

How to interpret RAM matches: “Tested at” means the upstream authors report using a system with that memory; it does not mean the model will fit any similarly sized computer. “Runtime minimum” means a project's published general requirement; it is not sufficient for every model. Results without source-specific memory measurements remain visible under “Any RAM budget.” Verify model, quantization, context length, CPU/GPU, and SSD before attempting to reproduce any test.
